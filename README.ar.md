# كروان (Kervan)

[![CodSpeed](https://img.shields.io/endpoint?url=https://codspeed.io/badge.json)](https://app.codspeed.io/Ercaner1988/kervan?utm_source=badge)
[![الباب الذهبي](https://img.shields.io/badge/alt%C4%B1n--kap%C4%B1-16%20dimensions-brightgreen)](#قواعد-الباب-الذهبي-والانضباط-البرمجي)

بوابة ذكاء اصطناعي شاملة وعالية الأداء ومحرك توجيه يجمع نماذج الذكاء الاصطناعي المتعددة تحت واجهة واحدة متوافقة مع OpenAI. مبني بالكامل بلغة Rust الصافية مع هيكل وحدات (20 حزمة)، وواجهة سطح مكتب أصلية باستخدام egui، ومجموعة أدوات Bun.

> يحمل الأحمال عبر مسارات متعددة، ويعرف مقدار ما يمكن لكل مسار تحمله بدقة.

---

## 📦 الميزات والبنية المعمارية

يجمع كروان بين جلسات المتصفح بدون مفاتيح API (مثل Gemini وClaude وPerplexity) وأكثر من 276 مزود ذكاء اصطناعي رسمي ومفتوح المصدر (OpenAI وAnthropic وGoogle وDeepSeek وQwen وMistral وOllama وغيرها) خلف نقطة نهاية موحدة متوافقة مع OpenAI.

* **276 مزوداً و5 محركات تنفيذ موحدة:** تنفيذ REST القياسي، رسائل Claude، محتوى Gemini، جلسات المتصفح، ومحرك تحديث رموز OAuth2.
* **19 استراتيجية توجيه مدمجة:** الأولوية، التوزيع الدوري (Round-Robin)، الموزون، الأقل استخداماً، المحسن للتكلفة، المحسن للسياق، المحسن للذاكرة المؤقتة، ومشاركة الحصص.
* **مرونة ثلاثية الطبقات:** قاطع الدائرة (Circuit Breaker)، متتبع التهدئة والتراجع الأسي، وقفل النموذج المؤقت/الدائم.
* **تحويل ثنائي الاتجاه بدون فقدان:** تحويل فوري لرسائل وتدفقات SSE بين صيغ OpenAI وClaude وGemini بزمن وصول أقل من ميكروثانية.
* **مستودع مشفر و193 ترحيل SQL:** قاعدة بيانات SQLite محلية مشفرة بـ AES-256-GCM + scrypt مع 134 جدولاً مطابقاً للمخطط الذهبي ودعم النسخ الاحتياطي الساخن `VACUUM INTO`.
* **بروتوكول A2A (v0.3):** خادم JSON-RPC 2.0 لإدارة المهام (`tasks.create`, `tasks.get`, `tasks.cancel`) وبطاقة العميل الآلي `/.well-known/agent.json`.
* **درع الحماية (القاعدة الصارمة #20):** حجب معلومات الهوية الشخصية PII (معطل افتراضياً)، إخفاء المفاتيح الحساسة (`[REDACTED_API_KEY]`)، وحماية تجريبية ضد حقن التوجيهات.
* **لوحات سطح مكتب تفاعلية (egui):** لوحة المؤشرات، إدارة النماذج والبحث في 276 مزوداً، ولوحة الأمان.
* **أدوات سطر الأوامر (CLI):** ترحيل تجريبي كخيار افتراضي (`kervan goc --uygula`)، النسخ الاحتياطي (`kervan yedekle`)، وفحص السلامة (`kervan dogrula`).

## 🚀 اختبارات الأداء (CodSpeed / Divan)

تُنفذ العمليات الأساسية في كروان بسرعات فائقة تقاس بالميكروثانية والنانوثانية:

| العملية | الزمن الوسيط | الوصف |
|---|---|---|
| **التحويل من OpenAI إلى Claude** | `~384 ns` | تسوية مخطط الطلب وفصل توجيه النظام |
| **التحويل من OpenAI إلى Gemini** | `~315 ns` | تحويل الطلب والمحتوى المتعدد الوسائط |
| **ترتيب أهداف التوجيه (19 استراتيجية)** | `~799 ns` | ترتيب الأهداف حسب التكلفة والسياق |
| **التشفير وفك التشفير (AES-256-GCM)** | `~1.39 µs` | تشفير وتأمين المفاتيح والرموز الحساسة |

## ⚙ التثبيت والتشغيل

### المتطلبات
* مترجم Rust 1.80+ (إصدار 2024)
* نظام تشغيل Windows أو Linux أو macOS

### البناء

```bash
git clone https://github.com/Ercaner1988/kervan.git
cd kervan
cargo build --release
cargo test --workspace --all-features
```

### التشغيل

```bash
# تشغيل الخادم في الخلفية (الافتراضي 127.0.0.1:20129)
./target/release/kervan

# تشغيل واجهة سطح المكتب:
cargo run --features gui
```

## 🛡 قواعد الباب الذهبي والانضباط البرمجي

يلتزم المشروع بمعايير هندسية صارمة:
1. **حد حجم الحزم:** كل حزمة من الـ 20 حزمة في مجلد `crates/` لا تتجاوز **1500 سطر برمجي** كحد أقصى.
2. **انعدام الانهيار (Zero Panic):** لا وجود لدوال `unwrap` أو `expect` في كود الإنتاج.
3. **أمان الحلقة المحلية:** الاستماع مقصور تماماً على `127.0.0.1` ولا يمكن الوصول إليه خارجياً.
4. **تنقية الأخطاء:** عدم تسريب أي أخطاء قاعدة بيانات خام أو تتبع استدعاءات للنظام للعملاء.
