بنية بوابة توجه استخدام الذكاء الاصطناعي من واجهات الويب إلى نقاط النهاية المطلوبة. Rust، ملف ثنائي واحد.

## العربية

### ماذا يفعل

يحوّل حسابات الذكاء الاصطناعي بدون مفاتيح API (واجهات Gemini و Claude و Perplexity) إلى نقطة نهاية واحدة متوافقة مع OpenAI. بدلاً من نسخ ملفات تعريف الارتباط، يشغّل **متصفحاً حقيقياً**: تسجيل الدخول مرة واحدة، والجلسة تبقى في دليل الملف الشخصي.

الفرق عن الحلول الموجودة في ثلاث نقاط:

- **عزل حقيقي لكل حساب** — كل حساب في ملفه الشخصي الخاص. وضع التصفح الخاص لا يكفي: كل نوافذ التصفح الخاص في نفس المتصفح تتشارك ملفاً شخصياً واحداً.
- **جلسة دائمة** — لا لصق لملفات تعريف الارتباط، لا تجديد عند دورانها.
- **بوابة بشرية** — لا يفشل بصمت عند جدار التحقق؛ يوقف الحساب، يجلب النافذة إلى المقدمة، ويتركك تحلّه. لا يحاول تجاوز كشف الروبوتات.

### الحالة

المرحلة 3 (وضع المجموعة) تعمل: عدة مزودين، **عدة حسابات**، ميزانية السرعة، بوابة بشرية.

| | |
|---|---|
| المتصفح | مبني على Firefox (Zen أو Firefox)، عبر geckodriver |
| نقطة النهاية | `POST /v1/chat/completions`، `GET /v1/models`، `GET /health` |
| المجموعة | `GET /accounts`، `POST /accounts/{i}/devam` |
| الربط | المضيف المحلي فقط (`127.0.0.1`) |

### المزودون

معرّفون: `gemini`، `kimi`، `copilot`، `copilot-m365`، `perplexity`، `claude`، `deepseek`، `qwen`، `z.ai`. كل حساب مرتبط بمزود واحد أو أكثر في `kervan.toml`.

#### حالة المزودين

| المزود | الحالة |
|---|---|
| `gemini` | ✅ في المجموعة — عدة حسابات، ~11 ثانية |
| `kimi` | ✅ في المجموعة — عدة حسابات، 25–36 ثانية |
| `copilot` | ✅ في المجموعة — حساب Microsoft شخصي، ~12 ثانية |
| `copilot-m365` | ✅ في المجموعة — حساب عمل/مدرسة، ~14 ثانية |
| `perplexity` | ⚠️ غير مستقر — Cloudflare على بعض الحسابات |
| `claude` | ❌ Cloudflare — مُعطّل في المجموعة |
| `deepseek` | ❌ Cloudflare — على معظم الحسابات |
| `qwen` | ❌ Cloudflare — على كل الحسابات |
| `z.ai` | ❌ Cloudflare — استجابة فارغة مضلّلة |

### متعلّم الحصة

مزودو الويب لا يكشفون الحصة المتبقية. كرفان يسجّل نتيجة كل طلب في `%LOCALAPPDATA%\kervan\kota.jsonl`، مع تحديد لحظات الوصول للحد.

```
curl http://127.0.0.1:20129/kota
```

- **لا اختلاق.** لا ينتج تقديرات بدون ملاحظة وصول للحد.
- رسالة الحد **لا تعاد كاستجابة** — العميل يحصل على 502.

### المتطلبات

- Rust 1.97+
- متصفح مبني على Firefox (Zen مدعوم)
- [geckodriver](https://github.com/mozilla/geckodriver/releases) — في `%LOCALAPPDATA%\kervan\bin\geckodriver.exe` أو في PATH

### الاستخدام

أول مرة: سجّل الدخول عبر نافذة مرئية (مرة واحدة).

```bash
cargo run -- profile-name --giris
```

ثم شغّل كبوابة:

```bash
cargo run -- --headless --serve
```

وضع الاستعلام الفردي:

```bash
cargo run -- profile-name --headless --sor "من هو معمار سنان؟"
```

### التهيئة (`kervan.toml`)

```toml
idle_minutes = 15         # أغلق المتصفح غير المستخدم لهذه المدة

[[accounts]]
name = "user@example.com"   # دليل الملف الشخصي = الحساب نفسه
providers = ["gemini", "perplexity"]

[pacing]
min_delay_ms = 3000       # الحد الأدنى للتأخير بين الطلبات لنفس الحساب
jitter_ms = 2000          # تذبذب عشوائي فوقه
hourly_cap = 30           # الحد الساعي لكل حساب
```

### التكامل مع Hermes

في `~/.hermes/config.yaml` كمزود `custom`:

```yaml
  - name: kervan
    base_url: http://127.0.0.1:20129/v1
    api_key: kervan-local
    model: kervan/gemini
    models:
      - kervan/gemini
      - kervan/copilot
```

### الأمان

- أدلة الملفات الشخصية تحتوي على ملفات تعريف الارتباط والجلسات، مدرجة في `.gitignore`.
- البوابة ترتبط فقط بـ `127.0.0.1`.
- كرفان لا يستطيع تسجيل الدخول بمفرده — التحقق دائماً يمر عبر إنسان.

**ما لا يفعله:** لا انتحال بصمة، لا حل CAPTCHA، لا دوران وكيل/IP، لا إخفاء توقيع الأتمتة.
